ESP32 Pin Configuration

Which ESP32 pin goes to which sensor and relay, how each one is powered, and the two voltage dividers that keep 5 V away from the 3.3 V pins. Source of truth: firmware/Full_code/Full_code.ino.

Pin positions follow the common DOIT ESP32 DevKit V1 (30-pin) board. On a 38-pin board the GPIO numbers are the same but the positions differ, so wire by the GPIO number printed on the board.

Protecting the 3.3 V pins

Voltage dividers

The ESP32 pins take at most 3.3 V. Two modules run on 5 V and can output more than that, so each gets a resistor divider.

pH output (Po → GPIO33)

Firmware multiplies back by PH_DIVIDER 1.5. A Po of 4.6 V is about 3.07 V at the pin (PH_ADC_LIMIT).

HC-SR04 echo (ECHO → GPIO17)

TRIG is driven straight from GPIO16. Each level reading is the median of 5 pings, corrected for air temperature.

Why these pins

  • Analog inputs on ADC1 (GPIO32, GPIO33). ADC2 pins cannot be read while Wi-Fi is active, so ADC1 keeps the design ready for that.
  • No strapping pins used (GPIO0, 2, 5, 12, 15). They decide the boot mode, and a sensor on them can stop the ESP32 from starting.
  • Relays default OFF. The firmware sets the relay pins to OFF before making them outputs, so the pumps do not kick on at boot (RELAY_ACTIVE_LOW true: LOW = ON).
