System Diagram & Flowchart

How data moves from the sensors through the ESP32, the USB cable and the MQTT broker to the logs, the camera AI and the dashboard, and how the firmware decides when to run the pumps.

1 · Architecture

Block diagram

sensor / relay wiring USB serial (JSON every 2 s) MQTT files on the Pi camera (USB-C network)

In short: the ESP32 is the only part that touches the hardware and it keeps dosing and protecting the pumps even if the Pi is off. The Pi adds memory (CSV logs), eyes (camera + AI) and a screen (dashboard). All links are local: a USB cable to the ESP32, USB-C to the camera, and MQTT on the Pi itself.
